# Phase 5.9.5-F / F2 全局文件浏览与响应式验收

## 目标

Phase F 原先只建立不可用空接口；用户在 2026-07-19 明确授权解除该边界，并要求按用户级体验补齐真实文件浏览。当前验收对象已经包括真实文件树、状态恢复和跨模块显式动作，不再以“左侧无 Pane”为通过标准。

## 已实现

- 独立且唯一的 `FolderBrowserModel`，不复用编辑器旧浅层浏览器。
- 基于 Qt `QFileSystemModel` 的原生异步懒加载、目录变更自动刷新和真实层级树。
- 只显示目录及受支持音频；NCM 可加入转码队列，但不会误开放直接播放或编辑。
- 显式选择根目录；当前根、收藏、最近目录、Pane 显示状态和 220～360 px 宽度写入应用配置并在重启后恢复。
- 文件名筛选、收藏/最近目录切换与清理、选择摘要和完整路径 tooltip。
- 选中行使用高对比背景、边框和左侧强调条；Windows 路径大小写或短路径差异不会导致高亮丢失。
- 底部摘要显示 46 px 内嵌封面小图。封面只读解析在后台完成，快速切换时只应用最新请求，并按文件大小与修改时间缓存有限结果。
- TreeView 禁用 delegate 复用，对每个 delegate 校验相对目录深度，并在结构变化后重新布局，防止异步展开时旧 delegate 被错误绘制到同级位置；不依赖载入瞬间可能暂时失配的扁平行索引。
- 单击只选择；箭头只展开/折叠；双击普通音频只载入唯一全局播放器，固定不自动播放、位置归零且不改变编辑文件。
- 普通音频可从文件树拖到音频编辑或自动转码主工作区；NCM 只允许拖到自动转码区。拖放继续调用现有编辑 dirty guard 或唯一队列入口。
- 拖动提示由 AppShell 窗口级浮层持有，跨出左侧 Pane 后继续跟随鼠标并保持到真实释放；取消拖动只清理提示，不执行导入或入队。
- 右键提供“载入播放器 / 在音频编辑中打开 / 加入转码队列 / 打开文件位置 / 复制文件路径”。
- 进入音频编辑继续经过统一 dirty guard；入队继续写入唯一 `TaskQueueModel`，来源显示“文件夹树”。
- `SplitView` 支持拖动宽度；Pane 可从卡片或顶部全局按钮收起/展开，隐藏后主工作区完整扩展。
- Preview 与 smoke 模式没有文件浏览能力，不恢复或读取真实根目录。
- 顶栏不显示运行模式和功能能力摘要黄色框；一级工作区、文件栏开关、设置、日志及版本仍可达，底层运行模式与能力守卫不变。

## 行为边界

- 选择、展开、筛选或文件系统自动刷新都不会自动加入任务、开始转换或切换播放器。
- 文件拖出后只有释放点位于当前主工作区才执行；释放到文件树、顶部栏或播放器不会导入或入队。
- 双击文件只改变 PlayerSession；右键“在音频编辑中打开”才会请求改变 EditorSession。
- 转换与编辑导出仍保留源文件、no-clobber 和现有发布事务。
- 本阶段没有修改 `converter.py`、FFmpeg/NCM/Pitch 算法、任务生命周期、导出服务或 Legacy Widgets。

## 自动化验收

- 临时中文/空格目录：根目录载入、目录/音频过滤、NCM 能力差异、搜索、原生目录刷新。
- 鼠标级 QML：连续六轮展开/折叠保持可见路径唯一，音频双击命中正确行，右键菜单打开/关闭，选中高亮生效。
- 封面：后台读取、过期请求隔离、无封面状态和按文件版本缓存。
- 拖放：文件 URL 桥接、编辑/转码能力差异、AppShell 工作区边界、窗口级提示生命周期和既有导入/入队入口。
- 接线：播放器来源 `folder_tree`、队列来源 `folder_browser`、编辑器 dirty guard 入口。
- 状态恢复：根目录、收藏、最近目录、Pane 显示状态和 220～360 px 宽度。
- 窗口：1080×680、1280×720、1440×900、1536×982、1900×1200、1920×1080。
- 播放器：799/800 高度边界。
- 检查器：1899×1200、1900×1199、1900×1200。
- 缩放：Qt 100% / 125% / 150%。
- 完整无缓存回归：`553 passed, 2 warnings, 70 subtests passed`。
