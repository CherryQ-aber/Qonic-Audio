# Qonic Audio Post-Install User State Acceptance

## 数据位置

- 配置：`%LOCALAPPDATA%\Qonic Audio\Config\config.json`
- 缓存：`%LOCALAPPDATA%\Qonic Audio\Cache\`
- 日志：`%LOCALAPPDATA%\Qonic Audio\Logs\runtime.log`
- 安装目录：只应包含程序、Qt/FFmpeg/ncmdump、QML 与静态资源。

测试前先完全退出 Qonic Audio（包括系统托盘）。如需模拟全新用户，先把
`%LOCALAPPDATA%\Qonic Audio` 重命名为带日期的备份目录；不要删除旧配置。

## 1. 真正全新安装

1. 确认用户数据目录已重命名备份，安装 Qonic Audio。
2. 以普通用户首次启动。
3. 确认窗口位于主显示器可用区域中央，并出现首次启动目录确认。
4. 确认界面只做候选检测，没有自动扫描、监听或转换。

## 2. 接受自动检测目录

1. 选择“使用此目录”，完全退出，再启动。
2. 确认监听目录保留，首次启动窗口不再出现。
3. 确认没有因接受目录而自动开始转换。

## 3. 暂时跳过

1. 使用另一份全新用户数据目录，首次启动选择“暂时跳过”。
2. 完全退出并重启，确认不重复提示。
3. 在设置中确认仍可手动选择监听目录。

## 4. 主题

1. 依次选择 Dark、Light、Black、Purple（以及“跟随系统”）。
2. 每次确认界面立即变化且显示“主题已保存”。
3. 完全退出并重启，确认恢复刚才选择的主题。

## 5. 普通窗口位置和尺寸

1. 将窗口移动到明显位置并调整尺寸。
2. 完全退出并重启，确认位置和尺寸基本一致。

## 6. 最大化

1. 最大化窗口后完全退出并重启。
2. 确认恢复最大化；恢复为普通窗口后，尺寸仍是最大化前的普通尺寸。

## 7. 多显示器与分辨率变化

1. 将普通窗口移动到第二显示器，退出并重启，确认合理恢复。
2. 再退出、拔掉第二显示器并启动，确认窗口回到主显示器可用区域。
3. 在较低分辨率/缩放下启动，确认窗口尺寸不超过可用区域且主操作仍可见。

## 8. 普通权限

1. 不使用“以管理员身份运行”。
2. 修改主题、监听目录、窗口位置和尺寸，退出并重启。
3. 确认所有状态均保留，日志没有配置保存失败。

## 9. 安装目录不可写

1. 保持安装目录的普通用户只读权限。
2. 重复主题、窗口、监听目录修改。
3. 确认 Config/Cache/Logs 只写入 `%LOCALAPPDATA%\Qonic Audio`。
4. 检查安装目录没有新生成 `config.json`、`settings.json`、运行缓存或用户日志。

## 10. 覆盖安装与旧配置迁移

1. 在旧版本中保留一份已有设置的 `config.json`，记录其 SHA-256。
2. 覆盖安装并启动新版。
3. 确认主题、目录和现有设置迁移到新的 Config 路径，且不弹首次启动。
4. 确认旧 `config.json` 内容和 SHA-256 未改变。
5. 再次覆盖安装，确认不会重复迁移或重置 `first_launch_completed`。

## 日志核对

在 `runtime.log` 中核对以下事件：用户配置/缓存/日志路径、已加载主题、窗口恢复结果、
是否需要 First Run、候选目录数量以及 legacy migration 结果。日志不应打印整个配置对象。
